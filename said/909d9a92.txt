Release 7.0.16 includes the following changes:

- API: fixed a bug in the web service SDK that could lead to a crash
- ExtPacks: updated the extension pack check to allow newer versions of VirtualBox with older extension packs
- ExtPacks: fixed a potential security issue with extension packs (CVE-2022-21263)
